# CacheDataLoader

Cache Util to load data into cache

## Contents

- **`/`** — the Coherence cache loader (Spring Boot, Maven). See `pom.xml` and
  `application.yml`.
- **[`testgen/`](testgen/)** — a standalone toolkit that builds prompts for
  generating automated test suites for any app. Reads an OpenAPI, GraphQL,
  or Postman spec and emits a single prompt covering test-design technique,
  coverage depth, and framework conventions. No dependency on the loader; it
  can be lifted into its own repository as-is.
